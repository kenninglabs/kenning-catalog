# Git

Distributed version control — the prerequisite for every other tool in this catalog that touches a repo (`github-cli`, `argocd-cli`'s config repos, `forward-porting`, `worktrees`, etc.).

- **Install docs:** https://git-scm.com/downloads
- **Reference:** https://git-scm.com/docs

## Verify

```bash
git --version
```

## First-time setup

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```
